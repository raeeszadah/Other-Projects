# 📖 Overview

RespawnID is a gamer-focused social networking platform that brings together a player's gaming profile, social connections, real-time communication, and gaming statistics into a single unified experience.

The platform enables gamers to connect their Steam accounts, interact with friends, discover gaming communities, and build their own digital gaming identity.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/raeeszadah/RespawnID.git
```

---

## Navigate

```bash
cd RespawnID
```

---

## Install Dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd server
npm install
```

---

## Environment Variables

Create a `.env` file.

```env
PORT=5000

MONGO_URI=

JWT_SECRET=

STEAM_API_KEY=

CLIENT_URL=
```

---

## Run Backend

```bash
npm run dev
```

---

## Run Frontend

```bash
npm start
```
